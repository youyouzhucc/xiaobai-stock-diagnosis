# 小白诊股（Xiaobai Stock Diagnosis）

一个面向新手的「说人话」A 股体检工具：把 ROE、PE、现金流、盈亏比这些专业指标，翻译成一句句能看懂的大白话，并给出估值 / 趋势 / 风险的分项打分和操作建议。

纯前端实现，无需构建、无后端依赖，数据全部来自公开接口实时拉取。

**综合分不是每次打开都现算**：由 GitHub Actions 在北京时间每天 12:05 跑一次 `scripts/build-scores.mjs`，把 30 只精选股的行情 / K 线 / 财报算成 `data/scores.json`，同时生成全市场估值排名 `data/ranks.json`。页面直接读这两份快照，全天展示同一套分数，不会出现「先占位、后逐只填」的过程。

## 数据都是真的

初版页面里的指标是写死的示例数字，这一版全部替换成真实数据：

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 实时行情（现价、涨跌、PE、PB、市值、换手率、量比、行业） | 东方财富 `push2` | 批量接口，一次拉整个股票池 |
| 历史 K 线（日线，前复权，近 1 年） | 东方财富 `push2his` | 真实历史价格，用于走势图与全部技术统计 |
| 财务指标（ROE、毛利率、净利率、资产负债率、每股经营现金流、营收/净利润及同比） | 东方财富 F10 财务报表 | 取最近已披露报告期，标注口径与披露日期 |
| 股息率（近 12 个月实际实施的现金分红 / 现价） | 东方财富 F10 分红实施记录 | 逐只取最近 8 条分红记录，按除息日落在近 12 个月内累加，税前口径 |

**没有数据的指标一律显示「—」并从评分中剔除，不做估算填补。**

## 评分模型

综合分 = 底子 40% + 估值 30% + 趋势 20% + 风险 10%（某项数据缺失时自动重新归一化权重）

- **底子**：ROE、毛利率、资产负债率、每股经营现金流 / 每股收益（金融股不评负债率，改看净利率）
- **估值**：PE(TTM)、PB、近一年价格分位
- **趋势**：收盘价与 20/60 日均线关系、20 日与 60 日涨跌幅、价格位置
- **风险**：近 60 日年化波动率、近一年最大回撤

所有阈值映射写在 `js/score.js` 里，可自行调整。

## 功能

| 模块 | 说明 |
| --- | --- |
| 精选池 | 30 只覆盖白酒、银行、保险、券商、新能源、半导体、医药、家电、汽车、光伏、消费电子等行业的代表股 |
| **主题榜单（首页）** | 一行 6 个方向：估值最便宜、便宜的大块头、近两月跌最狠、近两月涨最猛、突然放量、没什么人搭理。每个方向只列前 3 只，点股票直接体检、点「共 N 只」进全市场看完整名单 |
| **全市场浏览** | `market.html`：沪深两市 **5563 只** A 股。整张表一次载入（分 56 次请求、4 并发），之后筛选 / 排序 / 翻页全部本地计算，秒响应 |
| **全市场筛选** | 股票类型（10 类，按东财行业名归类）、市值三档、市盈率四档、换手活跃度、最近交易日涨跌；条件同步到地址栏，可收藏分享 |
| **全市场排序** | 代码、综合分数、最近交易日涨跌、近两月涨跌、市值、市盈率、市净率、换手率、量比（均为全市场范围排序，不是只排当前页） |
| **行业风向** | 全市场载入后按行业聚平均涨跌，一行灰字给出最强 / 最弱 3 个行业（样本少于 5 只不算） |
| **任意代码诊断** | 搜索框输入任意 6 位沪深 A 股代码（60/68/00/30 开头）即可现拉行情、财报、K 线出报告；也支持 `index.html?code=601398` 直接深链打开 |
| 搜索 | 名称 / 代码 / 拼音首字母（如 `茅台`、`600519`、`gzmt`）；搜索时自动收起榜单与全市场入口，只留结果 |
| 筛选（精选池） | 股票类型、市值、市盈率、今日活跃度、股息率、资金期限、风险承受、更看重、今日涨跌，全部基于真实指标判定 |
| 后台体检 | 每日 12:05 由定时任务统一算一次（见下节），页面直接读快照；快照缺失时退化为进页面后逐只现算 |
| 体检报告 | 综合结论、操作建议（热度 / 分批节奏 / 适合人群 / 跟踪防线） |
| 全市场排名 | 详情页展示该股在 5000 多只 A 股里的估值排名（按 PE、PB 综合排序，亏损股不参与） |
| 盈亏空间 | 以近一年真实最低价为地板、最高价为天花板，算下行/上行空间与赔率 |
| 走势图 | 真实 K 线 + 20 日均线 + 沪深300 同起点对比，支持 1 月 / 半年 / 1 年切换 |
| 名词解释 | 点击 ROE、PE、PB、价格分位等标签，弹出生生活化案例 |
| 最新财报 | 营收、归母净利润、同比、EPS、BPS，标注报告期 |
| **板块徽章** | 创业板 / 科创板 / 北交所的股票，名字后面带一个小徽章。这两类板块要单独开通权限才能买，主板开户即可，所以主板不标 |
| **购买门槛提示** | 详情页评分区下方给一句白话：创业板 20 个交易日日均资产 ≥ 10 万 + 满 2 年交易经验；科创板、北交所 ≥ 50 万 + 2 年。附「券商 App 里搜『创业板』」的查法 |
| **我的权限（自检）** | 筛选栏按钮，勾选自己已开通的板块，结果只存浏览器。勾过的板块徽章转灰、详情页提示转绿；还可开「只看我能买的」，把买不了的票直接滤掉 |

## 交易权限口径

只有三个板块设了买入门槛，其余沪深主板开户即可：

| 板块 | 代码开头 | 资金门槛 | 交易经验 |
| --- | --- | --- | --- |
| 创业板 | 300 / 301 | 前 20 个交易日日均 ≥ 10 万 | ≥ 24 个月 |
| 科创板 | 688 / 689 | 前 20 个交易日日均 ≥ 50 万 | ≥ 24 个月 |
| 北交所 | 43x / 83x / 87x / 92x | 前 20 个交易日日均 ≥ 50 万 | ≥ 24 个月 |

依据沪深交易所与证监会公开规则整理，实际审核以开户券商为准（部分券商会额外要求「20 日内至少 3 天资产达标」）。站内目前只覆盖沪深两市，不含北交所个股，所以标出来的实际是创业板与科创板。

## 技术栈

- 原生 HTML / CSS / JavaScript，零构建
- [ECharts 5.4.3](https://echarts.apache.org/)（CDN）绘制走势图
- 莫兰迪低饱和色系、卡片式布局，移动端优先
- 组件库 `js/ui.js`：卡片、栏目标题（标题 + 紧跟结论 + 分数）、指标块、进度条、标签、数字格式化。同类模块只写一遍，详情页与首页榜单共用
- 数据层统一走 `fetch` + AbortController 超时控制，带内存缓存与退避重试

## 每日分数快照

- 触发：`.github/workflows/daily-scores.yml`，`cron: '5 4 * * 1-5'`（UTC 04:05 = 北京 12:05，仅工作日），也支持在 Actions 页面手动 `Run workflow`。
- 内容：`data/scores.json`（30 只的总分与分项、行情统计、股息率）、`data/ranks.json`（5563 只股票的 PE/PB 综合估值排名表，约 50 KB）、`data/boards.json`（首页 6 个主题榜单，约 7 KB）。
- 口径：分数基于当天 12:00 前后的行情与最新已披露财报，**当天不再随盘中价格变化重算**；盘中的现价、涨跌、换手、量比仍是实时拉取的。
- 榜单口径与全市场页完全同源（同一份全市场数据、同一套筛选规则），两边的第一名不会打架。净筛：名字带「退」或「ST」、价格无效、停牌的一律不进榜 —— 它们的极端涨跌是制度原因，对新手是误导。
- 手动跑一次：`node scripts/build-scores.mjs`（Node 18+，需要能访问东方财富接口）。

## 加载性能

首屏只做三件事：拉一次行情、读一次当日分数快照、渲染卡片。其余全部延后或缓存：

| 手段 | 说明 |
| --- | --- |
| 图表库按需加载 | ECharts 约 1 MB，原先在 `<head>` 同步加载、阻塞首屏。现在移到详情页要画图时才加载，首屏完全不碰它；空闲时提前预热 |
| 并行请求 | 行情与 `scores.json` 同时发出，首屏耗时从「两次往返之和」降到「较慢的那一次」 |
| 按日缓存 | `scores.json` / `ranks.json` 一天只有一版，用日期做版本号，同一天内直接命中浏览器缓存，跨天自动换新 |
| 详情数据缓存 | 日线、财报、分红在会话内缓存 2 小时，反复进出详情页不再重复请求 |
| 预连接 | `preconnect` 到东方财富三个域名与 jsDelivr，省掉 DNS + TLS 往返 |

## 本地运行
```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

访问 http://localhost:8000 即可（直接双击 `index.html` 也能跑，但部分浏览器对本地文件有跨域限制，建议起静态服务）。

## 已知限制

- 数据来自第三方公开接口，非交易所级行情，可能有延迟；接口偶发限流时会显示「数据不全」并提供重试。
- 综合分每天只算一次（12:05），盘中价格变化不会改变分数；想看当天最新价格看行情区即可。
- 估值排名只覆盖 PE、PB 均为正的股票（约 3800 只），亏损股与缺数据的股票不参与。
- 走势图为日线前复权，不含分时/分钟级。
