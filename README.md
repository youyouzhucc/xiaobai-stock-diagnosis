# 小白诊股（Xiaobai Stock Diagnosis）

一个面向新手的「说人话」股票诊断单页应用：把 ROE、PE、现金流、盈亏比这些专业指标，翻译成一句句能看懂的大白话，并给出操作建议、分批买入节奏和跟踪防线。

纯前端单文件实现，无需构建、无后端依赖，直接双击 `index.html` 即可运行。

## 在线体验

部署在 GitHub Pages 上，打开即用：

> https://youyouzhucc.github.io/xiaobai-stock-diagnosis/

## 功能

| 模块 | 说明 |
| --- | --- |
| 股票列表 | 支持关键词搜索 + 资金期限 / 风险承受 / 看重维度三个下拉筛选 |
| 综合评分 | 底子 40% + 估值 30% + 趋势 20% + 风险 10% 加权，附「击败全市场 xx%」锚点 |
| 操作建议 | 按「估值 + 趋势」组合给出大白话建议、分批买入节奏、适合人群、跟踪防线 |
| 盈亏空间测算 | 给出极低支撑价、合理目标价、下跌/上涨空间与盈亏比 |
| 公司底子 | ROE、经营现金流、有息负债率三张迷你卡片 |
| 估值水平 | PE 历史分位、当前 PE、股息回报 |
| 近期趋势 | ECharts 走势图（近 1 月 / 半年 / 1 年），叠加沪深 300 对比与「走势人话翻译」 |
| 名词解释 | 点击 ROE、PE、股息率等标签弹出生动的生活化案例 |
| 近期动态 | 公司新闻 + 利好/利空标签 + 一句话 AI 解读 |

## 技术栈

- 原生 HTML / CSS / JavaScript，零构建
- [ECharts 5.4.3](https://echarts.apache.org/)（CDN 引入）绘制走势图
- 实时行情：腾讯行情接口 `qt.gtimg.cn`（现价、PE、总市值）
- 设计风格：莫兰迪低饱和色系 + 卡片式布局，移动端优先

## 本地运行

方式一：直接双击 `index.html`。

方式二：起一个本地静态服务（推荐，避免部分浏览器对本地文件的限制）：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后访问 http://localhost:8000

## 数据说明

- 页面内置的 `stockDB` 为**演示用样本数据**（贵州茅台、宁德时代、比亚迪），仅用于展示交互与文案逻辑。
- 现价、PE、市值通过腾讯行情接口实时拉取；若接口不稳定或跨域受限，页面会显示 `--`。
- 走势图曲线为模拟数据，用于展示图表交互与文案，不代表真实历史行情。
- 新闻解读为示例文本，非实时资讯。
